# Personal Website on AWS

## Overview
This project will be a personal website hosted on AWS and connected to a custom domain. The site will function like an expanded resume and portfolio, with sections for my background, certifications, projects, skills, and contact links.

The goal is to build a simple, professional cloud project that is low-cost, easy to maintain, and useful as a central hub for my work.

---

## Project Goals
- Build a personal website that acts as an expanded resume
- Host the site using AWS services
- Connect the site to a custom domain
- Use the project to refresh and strengthen my AWS skills
- Create a professional portfolio site that can link to GitHub, LinkedIn, resume, and future projects

---

## Planned Features
- Home page / introduction
- About me section
- Certifications section
- Projects section
- Skills section
- Contact / links section
- Resume download link
- Clean and simple design

---

## Planned AWS Services
- Amazon S3 for static website hosting
- Amazon CloudFront for content delivery and HTTPS
- AWS Certificate Manager (ACM) for SSL/TLS certificate
- Route 53 or external registrar for domain and DNS management

---

## Why This Project Matters
This project will help demonstrate:
- AWS static website hosting
- Domain and DNS configuration
- HTTPS setup
- CloudFront distribution usage
- Cost-conscious cloud design
- Portfolio and personal branding
